# 憨憨保种区多时间版（HanHanRescueSeedingMulti）

一个 MoviePilot v3 插件，fork 自 [Seed680/憨憨保种区](https://github.com/Seed680/MoviePilot-Plugins) v2.0.0，**独立命名发布，与原版互不冲突，可以同时安装**。

## 与原版的差异

只有一处功能差异，其余逻辑与原版 v2.0.0 完全一致：

| | 原版（Seed680） | 本插件 |
|---|---|---|
| 执行时间 | 只能填一个 cron 表达式 | 可填**多个** cron 表达式，每个时间点独立运行一次 |
| 插件 ID | `HanHanRescueSeeding` | `HanHanRescueSeedingMulti` |

其余功能（保种人数区间筛选、种子体积筛选、下载器选择、自定义标签、通知、下载记录、历史保种任务等）与原版完全相同，后续如原版更新，本插件会跟进同步。

## 适用场景

以憨憨保种区为例：保种资源每天 14:11 左右开始上新，但不是一次性全部放出，分批持续一段时间。只设一个较晚的时间点会漏掉"上新晚于执行时间"的资源，只设 14:11 又会漏掉"14:11 之后才上新的"。多个时间点可以首拉 + 补拉结合：

```
11 14 * * *;30 15 * * *
```

表示每天 **14:11** 和 **15:30** 各拉取一次。已下载过的种子由下载器按种子哈希自动去重，不会重复下载。

## 多时间写法

运行时间一栏用**分号（英文 `;` 或中文 `；`）、竖线 `|` 或换行**分隔多个 cron 表达式：

```
11 14 * * *;30 15 * * *
```

等价于：

```
11 14 * * *
30 15 * * *
```

- 每个表达式独立注册一个定时任务，互不影响；
- 无效的表达式自动跳过并在日志中提示，不影响其他表达式；
- 只填一个表达式时行为与原版完全一致。

## 安装

在 MoviePilot v3 的插件市场安全令牌/市场列表中添加本仓库：

```
https://github.com/Energumen2tap/MoviePilot-Plugins
```

然后在插件市场中搜索"憨憨保种区多时间版"安装。
